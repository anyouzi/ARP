# OpenAR — 桌面自动化工作流引擎

基于 Python 的可视化工作流编辑器 + 执行引擎，通过图像匹配 / 文字识别触发点击、滑动、按键等操作，支持桌面和 Android (ADB) 两种控制模式。

## 功能概览

- **可视化编辑器** — tkinter GUI，拖拽式管理 Task → Block → Code
- **图像匹配** — OpenCV 模板匹配，在屏幕截图中定位目标并执行动作
- **文字识别** — easyocr 中英文 OCR，匹配屏幕文字后触发动作
- **多种动作** — 点击、滑动、长按、按键、等待、循环控制
- **桌面控制** — 通过窗口标题/显示器索引定位，支持区域裁剪
- **ADB 控制** — 通过 ADB 连接 Android 设备/模拟器
- **模板系统** — 可保存/导入 Block 模板，快速复用常用操作
- **截图工具** — 内置全屏/框选截图，自动归档到项目 data 目录
- **导入导出** — JSON + ZIP 打包，便于分发和迁移

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

核心依赖：`opencv-python` `numpy` `mss` `pyautogui` `Pillow` `easyocr`

### 启动编辑器

```bash
python openar_editor.py
```

快捷键：`Ctrl+N` 新建 · `Ctrl+O` 打开 · `Ctrl+S` 保存 · `F5` 运行

## 工作流结构

```
Project (项目)
 └─ Task[] (任务列表, 顺序执行)
     └─ Block[] (代码块, 循环体)
         └─ Code[] (单条指令)
```

### Block 循环体

一个 Block 是一个 `do-while` 循环：
1. 截一次屏
2. 按顺序检查每条 Code 的触发条件
3. 条件满足则执行对应动作
4. 重复直到被 `退出循环` (stop_loop) 指令打断

### Code 指令

每条指令包含 **触发条件** + **执行动作**：

| 触发条件 | 说明 |
|---------|------|
| 无条件 | 直接执行 |
| 匹配图片 | 在屏幕上匹配模板图片，达到阈值则触发 |
| 文字识别 | OCR 识别屏幕文字，包含指定文本则触发 |
| 超时 | Block 循环累计时间超过阈值则触发 |

| 执行动作 | 说明 |
|---------|------|
| 点击 | 在匹配位置 + 偏移坐标处点击 |
| 滑动 | 从起点滑动到终点 |
| 长按 | 在匹配位置长按指定时间 |
| 按键 | 发送 Android keyevent 按键码 |
| 等待 | 等待指定毫秒 |
| 退出循环 | 跳出当前 Block，进入下一个 |
| 退出任务 | 提前结束当前 Task |
| 退出程序 | 退出整个程序 |

## 编辑器使用

1. 启动编辑器后点击 **新建** 或 `Ctrl+N` 创建项目
2. 在项目文件列表中选中项目
3. 点击 **+ 添加任务**，再选中任务后 **+ Block**，再 **+ 指令**
4. 在指令弹窗中选择触发条件和执行动作，填写参数
5. 匹配图片条件可通过 **浏览** 选择或 **截图** 获取模板
6. `Ctrl+S` 保存，`F5` 运行

### 典型模式

> **匹配点击跳出**：Block 末尾加 `[匹配目标 → 退出循环]`，即可在命中后跳转到下一 Block

## 桌面模式配置

- **控制器** — 选择"桌面"
- **窗口标题** — 留空匹配整个桌面，或填入目标窗口标题（如 "记事本"）
- **裁剪区域** — 格式 `x,y,w,h`，仅在此区域内截图和操作（比全屏快）
- **显示器** — `device_index`：0=全部，1=主屏，2=副屏……

## ADB 模式配置

- **控制器** — 选择"ADB"
- 确保 `adb devices` 能看到设备
- 修改 `adb_path` 为设备 IP 或序列号，`adb_port` 为 ADB 端口
